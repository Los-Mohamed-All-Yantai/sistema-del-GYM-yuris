# Yuri's Gym - Sistema de Gestión Completo (Sprint 1) 🏋️‍♂️💻

¡Bienvenido al repositorio oficial del **Sistema de Información Web para Yuri's Gym**! Este proyecto nace de la necesidad de digitalizar, optimizar y centralizar los procesos operativos de un gimnasio de mediana escala, sustituyendo el registro manual tradicional por una plataforma web moderna, rápida y eficiente.

Desarrollado como parte de la asignatura **Modelado de Base de Datos** en la **Universidad Andina del Cusco**.

## 🚀 Características Principales (Alcance del Sprint 1)

El sistema abarca la planificación y prototipado de los siguientes módulos esenciales:

* **📌 Módulo de Inscripciones:** Registro ágil de socios (< 2 minutos), tipos de membresías y alertas automatizadas de vencimiento.
* **📦 Módulo de Inventario:** Control de stock en tiempo real para suplementos y accesorios, con alertas de stock mínimo.
* **🛒 Módulo de Ventas (POS):** Registro de ventas individuales, emisión de comprobantes rápidos y resumen de caja diario.
* **📊 Módulo de Reportes:** Gráficos estadísticos de ingresos, flujo de socios activos/inactivos y productos más vendidos.
* **🔒 Módulo de Administración:** Gestión de usuarios del sistema con roles diferenciados (Administrador / Recepcionista).

## 🛠️ Stack Tecnológico Propuesto

* **Backend:** Laravel (PHP)
* **Frontend:** Blade Templates + Tailwind CSS (SaaS Look & Feel)
* **Base de Datos:** MySQL / PostgreSQL (Modelado en proceso)
* **Prototipado e IA:** Google Stitchs & Google AI Studio (Gemini Flash)

## 📂 Estructura del Proyecto (Metodología Design Thinking)

### 🧩 Fase 1: Empatizar y Definir
* **Investigación de Campo:** Entrevistas clave al Administrador (necesidad de alertas y control de stock) y al Recepcionista (necesidad de búsquedas rápidas y cierres de caja).
* **User Persona:** Creación de *Carlos Mamani* (34 años), quien busca centralizar el control del negocio en una sola pantalla.
* **Problem Statement:** *"Yuri, administrador de un gimnasio en crecimiento, necesita una forma de gestionar inscripciones, inventario y ventas de manera centralizada y ágil porque el control manual actual genera errores y demoras."*

### 💡 Fase 2: Idear
* **Lluvia de Ideas:** Estructurada originalmente mediante prototipos rápidos y desplegada en la web de GitHub Pages.
* 🔗 **[Link a la Lluvia de Ideas en producción](https://los-mohamed-all-yantai.github.io/LLuvia-de-ideas-proyecto3.1/)**

### 🤖 Fase 3: Prototipado con Inteligencia Artificial
Para acelerar el diseño de la interfaz de usuario (UI), se utilizaron prompts avanzados y estructurados en herramientas de Google:
1.  **Google Stitchs:** Generación de layouts iniciales, componentes de control de acceso rápido y paletas de colores de alto contraste (estilo deportivo elite).
2.  **Google AI Studio:** Uso de *System Prompts* avanzados para definir la arquitectura de la interfaz en Grid, lógica de negocio en el POS, atajos de teclado y estados interactivos (*Hover, Active, Focus*) usando Tailwind CSS.

## 🖼️ Vista Previa del Prototipo Final

El resultado del Sprint 1 es un Dashboard administrativo de alta fidelidad (**Yuri's Gym POS / MarketFlow**) que incluye:
* Métricas en tiempo real (Socios Activos, Retirados, Ingresos del día).
* Gráfico vectorial dinámico de **Tráfico y Aforo de Socios** por horas pico.
* Sección de control crítico de suplementos faltantes.
